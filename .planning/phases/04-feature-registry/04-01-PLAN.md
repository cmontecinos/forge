<task type="auto">
  <name>Task 1: Create Feature interface and registry</name>
  <files>internal/features/feature.go, internal/features/registry.go</files>
  <action>
    1. Create internal/features/feature.go with Feature interface:
       ```go
       type Feature interface {
           ID() string              // "auth", "database", "api"
           Name() string            // "Auth - Login/registro via backend"
           Description() string     // Longer description
           CompatibleStacks() []string  // ["web", "mobile"] or nil for all
       }
       ```

    2. Create internal/features/registry.go with (mirror stacks pattern):
       - Global registry: `var registry = make(map[string]Feature)`
       - sync.RWMutex for thread-safe access
       - Register(feature Feature): adds to registry
       - Get(id string) (Feature, bool): retrieves by ID
       - All() []Feature: returns all registered features (sorted by ID)
       - IDs() []string: returns all feature IDs
       - ForStack(stackID string) []Feature: returns features compatible with given stack
  </action>
  <verify>go build ./internal/features/...</verify>
  <done>Feature interface defined, registry with Register/Get/All/IDs/ForStack functions</done>
</task>
