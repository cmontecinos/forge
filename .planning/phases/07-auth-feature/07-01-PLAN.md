  <files>/tmp/forge-template-web/backend/internal/auth/handlers.go, /tmp/forge-template-web/backend/internal/auth/types.go, /tmp/forge-template-web/backend/internal/supabase/client.go</files>
  <action>
Create auth infrastructure in the web template backend:

1. **internal/supabase/client.go** - Supabase client wrapper:
   - NewClient(url, key string) function
   - Use supabase-go library (github.com/supabase-community/supabase-go)
   - Methods for auth operations (SignUp, SignIn, SignOut, RefreshToken)

2. **internal/auth/types.go** - Auth request/response types:
   - RegisterRequest (email, password)
   - LoginRequest (email, password)
   - AuthResponse (access_token, refresh_token, user)
   - RefreshRequest (refresh_token)
   - User struct (id, email, created_at)

3. **internal/auth/handlers.go** - Auth HTTP handlers:
   - Register(c echo.Context) - POST /auth/register
     - Validate input, call Supabase SignUp, return tokens
   - Login(c echo.Context) - POST /auth/login
     - Validate input, call Supabase SignIn, return tokens
   - Refresh(c echo.Context) - POST /auth/refresh
     - Validate refresh token, get new access token
   - Logout(c echo.Context) - POST /auth/logout
     - Invalidate session (best effort)

4. **Update go.mod** - Add supabase-go dependency

5. **Update routes.go** - Add auth routes:
   - auth := s.echo.Group("/auth")
   - auth.POST("/register", s.authHandler.Register)
   - auth.POST("/login", s.authHandler.Login)
   - auth.POST("/refresh", s.authHandler.Refresh)
   - auth.POST("/logout", s.authHandler.Logout)

Use proper error handling and HTTP status codes (400 for validation, 401 for auth errors, 500 for server errors).
  </action>

  <done>Auth handlers created with register, login, refresh, logout endpoints</done>

1. **internal/auth/middleware.go** - JWT validation middleware:
