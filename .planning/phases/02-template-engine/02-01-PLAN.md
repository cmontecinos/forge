<task type="auto">
  <name>Task 1: Create template engine with Git clone support</name>
  <files>internal/templates/engine.go, go.mod, go.sum</files>
  <action>
    1. Add go-git dependency: `go get github.com/go-git/go-git/v5`

    2. Create internal/templates/engine.go with:
       - TemplateData struct containing template variables:
         - ProjectName string
         - StackType string (web/mobile)
         - Features []string

       - CloneTemplate(repoURL, destDir string) error
         - Use git.PlainClone to clone repo to destDir
         - Handle ErrRepositoryAlreadyExists
         - Support --depth=1 for shallow clone (faster)

       - ProcessTemplates(dir string, data TemplateData) error
         - Use filepath.Walk to traverse all files
         - Skip .git directory
         - For each file: read, parse as text/template, execute with data, write back
         - Handle binary files gracefully (skip template processing)
         - Use {{.ProjectName}}, {{.StackType}}, {{.Features}} variables

       - CleanupGitDir(dir string) error
         - Remove .git directory after cloning (we don't want template's git history)

    3. Important: Skip files that fail template parsing (binary files, etc.)
       Use a simple heuristic: if file contains null bytes, skip template processing.
  </action>
  <verify>
    go build ./cmd/forge (compiles with go-git dependency)
  </verify>
  <done>Template engine created with Clone, Process, and Cleanup functions</done>
</task>
