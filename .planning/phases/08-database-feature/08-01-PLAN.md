<task type="auto">
  <name>Task 1: Add database methods to Supabase client</name>
  <files>/tmp/forge-template-web/backend/internal/supabase/database.go</files>
  <action>
Create database.go in the supabase package with CRUD operations using PostgREST API:

1. **internal/supabase/database.go** - Database operations:
   - Generic query builder types:
     - QueryOptions: Select, Filter, Order, Limit, Offset
     - FilterOperator: eq, neq, gt, gte, lt, lte, like, ilike, in

   - CRUD methods on Client:
     - From(table string) *QueryBuilder - Start a query
     - QueryBuilder.Select(columns ...string) - Specify columns
     - QueryBuilder.Filter(column, operator, value) - Add filter
     - QueryBuilder.Order(column string, ascending bool) - Order results
     - QueryBuilder.Limit(n int) - Limit results
     - QueryBuilder.Single() - Expect single result
     - QueryBuilder.Execute(result interface{}) error - Run query
     - Insert(table string, data interface{}) error - Insert row(s)
     - Update(table string, data interface{}, filters ...Filter) error - Update row(s)
     - Delete(table string, filters ...Filter) error - Delete row(s)

   - Use Supabase PostgREST conventions:
     - GET /rest/v1/{table}?select=*&column=eq.value
     - POST /rest/v1/{table} with JSON body
     - PATCH /rest/v1/{table}?column=eq.value with JSON body
     - DELETE /rest/v1/{table}?column=eq.value

   - Include apikey and Authorization headers
   - Return proper errors for failed requests

2. **Update internal/supabase/client.go** if needed:
   - Ensure Client struct is accessible for database methods
  </action>
