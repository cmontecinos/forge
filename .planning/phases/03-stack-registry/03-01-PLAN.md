<task type="auto">
  <name>Task 1: Create Stack interface and registry</name>
  <files>internal/stacks/stack.go, internal/stacks/registry.go</files>
  <action>
    1. Create internal/stacks/stack.go with Stack interface:
       ```go
       type Stack interface {
           ID() string              // "web", "mobile"
           Name() string            // "Web (Next.js + Go + Supabase)"
           Description() string     // Short description
           TemplateConfig() templates.TemplateConfig
       }
       ```

    2. Create internal/stacks/registry.go with:
       - Global registry: `var registry = make(map[string]Stack)`
       - Register(stack Stack): adds to registry
       - Get(id string) (Stack, bool): retrieves by ID
       - All() []Stack: returns all registered stacks (sorted by ID for consistent order)
       - IDs() []string: returns all stack IDs

    3. Use sync.RWMutex for thread-safe registry access (good practice even if not needed now).
  </action>
  <verify>go build ./internal/stacks/...</verify>
  <done>Stack interface defined, registry with Register/Get/All/IDs functions</done>
</task>
