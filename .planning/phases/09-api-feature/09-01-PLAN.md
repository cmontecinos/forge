  <name>Task 1: Create error helpers and item handlers</name>
  <files>/tmp/forge-template-web/backend/internal/server/errors.go, /tmp/forge-template-web/backend/internal/server/items.go</files>
  <action>
1. **internal/server/errors.go** - Consistent error responses:
   - ErrorResponse struct: Code, Message, Details (optional)
   - Helper functions:
     - BadRequest(c, message) - 400
     - Unauthorized(c, message) - 401
     - Forbidden(c, message) - 403
     - NotFound(c, message) - 404
     - InternalError(c, message) - 500
   - ValidationError(c, errors map[string]string) - 400 with field errors

2. **internal/server/items.go** - Item CRUD handlers:
   - ItemHandler struct with repository
   - NewItemHandler(repo *repository.ItemRepository)

   Handlers (all require JWT auth, user extracted from context):
   - ListItems(c) GET /api/v1/items - List user's items
   - GetItem(c) GET /api/v1/items/:id - Get single item
   - CreateItem(c) POST /api/v1/items - Create new item
   - UpdateItem(c) PATCH /api/v1/items/:id - Update item
   - DeleteItem(c) DELETE /api/v1/items/:id - Delete item

   Each handler should:
   - Extract user_id from JWT context using custommw.GetUserID(c)
   - Get access token from Authorization header for RLS
   - Use repository methods
   - Return appropriate errors using error helpers
   - Return proper HTTP status codes (200, 201, 204, 400, 404, 500)
  </action>
